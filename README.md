# Credit Risk Platform

A production-grade end-to-end machine learning platform for predicting loan default risk.

## Project Goals

- Understand credit risk from a business perspective
- Build robust ML models for probability of default
- Explain model predictions using SHAP
- Deploy using FastAPI
- Monitor model performance and data drift
- Demonstrate production ML engineering practices

## Tech Stack

- Python
- Pandas
- Scikit-learn
- XGBoost
- LightGBM
- CatBoost
- SHAP
- FastAPI
- Docker
- MLflow
- Evidently AI
